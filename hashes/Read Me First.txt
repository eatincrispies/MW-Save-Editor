NFSMW Save Editor hashes
by eatincrispies

These are the values Most Wanted keeps in its saves, for anyone who wants
to poke around with a hex editor. If you just want to change something,
the editor is a lot safer. Always work on a copy of your save.


What's in here

  Vehicles      Hashes for stock cars, bosses, presets, cops and traffic
  Parts         Body kits, spoilers, rims, hoods and roof scoops per car
  Visuals       Paints, vinyls, tint, decals, numbers and gauges
  Career        Blacklist ranks, races, markers, flags and impound states
  Save Layout   Where everything is in the file


Byte order

PC, PS2 and original Xbox store numbers backwards compared to Xbox 360
and GameCube. That's why every list has two byte columns, and original
Xbox uses the PC/PS2 one. Take the BMW M3 GTR:

  Vehicle Key    4E085FB3
  PC / PS2       B3 5F 08 4E
  360 / GC       4E 08 5F B3

Search your hex editor for the column that matches your platform.


Hashes vs save values

Cars, races and presets are saved as 4-byte hashes.

Parts are different. The save holds a 2-byte Save Value, so use that one
when you edit a part slot. The Name Hash is what the game's data and
Unlimiter preset files use.

Save Values are for the unmodded game. If your game has mods that add
parts, the numbers can shift.


Finding things in the file

Every offset counts from the start of the save data. Search for the text
20CM on PC, PS2 and original Xbox, or MC02 on Xbox 360 and GameCube. On
PC it's the very first thing in the file.

  PC         Edit the profile file directly.
  PS2        Use a .psu. The .max and .cbs formats are compressed.
  GameCube   Edit the .gci.
  Xbox 360   Edit a raw Xenia save, or extract the file from the CON
             package first. Don't edit the CON directly.
  OG Xbox    Edit the file named after your alias. Ctrl+S re-signs it
             with the same kind of key it came with.


Fix the checksums when you're done

The save has checksums, and hex editing breaks them. When you're done,
open the file in NFSMW Save Editor and press Ctrl+S. That rebuilds them
so the game will accept your save.
