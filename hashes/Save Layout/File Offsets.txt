File Offsets
============

Offsets are in hex and count from the first byte of 20CM (PC, PS2, original Xbox) or MC02 (Xbox 360, GameCube).

Data                    Size            PC     PS2    PS2 Early  Xbox 360  GameCube  Original Xbox
----------------------  --------------  -----  -----  ---------  --------  --------  -------------

Cash                    4 bytes         04039  04039  04039      04039     04039     04069
